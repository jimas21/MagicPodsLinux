# Moved to Tragus

The Steam Frame menu that lived here is now part of **[Tragus](https://github.com/jimas21/tragus)**,
one project with the earbuds service, the menu in Steam's VR interface and a one-click
installer.

**Install, updates and everything else: <https://github.com/jimas21/tragus>.**

This repository is kept read-only for history. It was a fork of
[MagicPods for Linux](https://github.com/steam3d/MagicPodsLinux) by
[Aleksandr Maslov](https://github.com/steam3d) and
[Andrey Litvintsev](https://github.com/andreylitvintsev); the original project's README is in
[docs/UPSTREAM-README.md](docs/UPSTREAM-README.md). Licence: GPL-3.0.
